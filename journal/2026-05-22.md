# 2026-05-22

## What I worked on

Added `npm run snapshot` — a Playwright Node.js script that captures full-page screenshots of every app route (empty state and with sample todos) and archives them to `snapshots/YYYY-MM-DD_HHMM/`.

## Decisions made

Used a `postSetup` pattern (UI interaction after navigation) to inject sample todos instead of localStorage injection, because the app stores todos in remoteStorage/IndexedDB rather than raw localStorage. Both IDB and localStorage are cleared between routes via `indexedDB.databases()` for clean-state isolation.

## What I learned

The `PageFooter` component renders a Chakra `<Text>` (which becomes `<p>`), not a `<footer>` element, so the two-pass height measurement falls back to `document.documentElement.scrollHeight` on every route.

## Problems / friction

No `<footer>` element means the footer-bottom measurement always uses the scrollHeight fallback. Not a problem for this single-route app, but worth noting if a semantic footer is added later.
