# Journal — 2026-05-22

## Summary

Added `npm run snapshot` — a Playwright Node.js script that captures full-page screenshots of every app route (empty state and with sample todos) and archives them to `snapshots/YYYY-MM-DD_HHMM/`. The `PageFooter` renders a Chakra `<Text>` (a `<p>` element), not a `<footer>`, so the two-pass height measurement falls back to `document.documentElement.scrollHeight` on every route.
